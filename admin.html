How to get your access token
  1. On GitHub tap your profile picture, then Settings.
  2. Scroll to the bottom of the menu and tap Developer settings.
  3. Tap Personal access tokens, then Fine-grained tokens, then Generate new token.
  4. Name it Samples admin. Set Expiration to 90 days.
  5. Under Repository access choose Only select repositories and pick your researchgeniushub.github.io repository.
  6. Under Permissions, then Repository permissions, find Contents and set it to Read and write.
  7. Tap Generate token and copy it. It starts with github_pat_. You only see it once.

The token is kept only in this browser on this phone. Never share it. You can delete it on GitHub at any time.
