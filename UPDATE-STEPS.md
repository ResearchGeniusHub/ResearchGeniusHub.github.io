# Update steps (phone friendly)

1. Supabase > SQL Editor > New query > paste the whole file `RUN-THIS-IN-SUPABASE.sql` > Run. (Safe to run again.)
2. GitHub > upload ALL files from this folder to the repository (replace existing).
3. Admin > Staff: add staff. Admin > Sample access: confirm payments. No Edge Function is needed for these.
4. Optional, so students can read/download PDFs: Supabase > Edge Functions > Deploy a new function > Via Editor,
   name `rgh-sample`, paste `rgh-sample-FUNCTION.ts`, turn OFF "Verify JWT", Deploy.
